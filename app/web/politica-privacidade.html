Política de Privacidade

Última atualização: 24 de outubro de 2026.

1. Dados coletados

Coletamos os dados enviados no formulário de proposta, como nome, empresa, e-mail, telefone, contexto técnico e mensagem. Evite enviar senhas, tokens, chaves ou dados sensíveis desnecessários.

2. Finalidade

Usamos os dados para responder solicitações comerciais, entender o escopo informado, prestar atendimento e manter registros necessários da conversa. Não transmitimos dados pessoais para ferramentas de analytics.

3. Analytics e consentimento

As métricas de navegação só são ativadas após consentimento no banner. O site registra eventos agregados, como visualização de página, clique em CTA e início de formulário. Abrir o WhatsApp não significa que um lead foi recebido.

4. Compartilhamento e retenção

Compartilhamos dados somente quando necessário para atender a solicitação, cumprir obrigação legal ou proteger direitos. Mantemos os dados pelo tempo necessário à finalidade e às obrigações aplicáveis.

5. Direitos e contato

Para dúvidas ou solicitações relacionadas a dados pessoais, escreva para privacidade@abreuebrum.com.br. Também é possível usar o formulário comercial para dúvidas gerais.
