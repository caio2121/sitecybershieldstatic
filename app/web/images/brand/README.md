# ABREU & BRUM Brand Assets

Official source files live in `app/LOGOTIPO NOVA ABREU & BRUM - 08072026`.

Use these public aliases in the site:

- `abreu-brum-logo-color.svg`: full logo on light backgrounds.
- `abreu-brum-logo-white.svg`: full logo on dark backgrounds.
- `abreu-brum-logo-black.svg`: monochrome logo for neutral print or special cases.
- `abreu-brum-logo-white-cutout.svg`: alternate white cutout logo.
- `abreu-brum-logo-black-cutout.svg`: alternate black cutout logo.
- `abreu-brum-crest-color.svg`: crest for favicon, avatar, and compact UI marks.
- `abreu-brum-crest-white.svg`: crest on dark backgrounds.
- `abreu-brum-crest-black.svg`: monochrome crest.
- `templates/abreu_brum_template_16x9.png`: Open Graph / social cards (16∶9).

Stable aliases used by HTML and metadata:

- `/images/logo-abreu-brum.svg`
- `/images/logo-abreu-brum-branca.svg`
- `/images/logo-abreu-brum-preta.svg`
- `/images/logo-favicon.svg`
- `/images/logo-social.svg` (crest; prefer `/images/og-16x9.png` for `og:image`)
- `/images/og-16x9.png` (Open Graph 16∶9)
- `/images/logo-crest-color.svg`
- `/images/logo-crest-white.svg`
- `/images/logo-crest-black.svg`

SVGs use a cropped `viewBox` (ink bounds). CSS is height-driven (`height` + `width: auto`).

When new official variations are added, copy them here and update these aliases instead of redrawing or editing the brand manually.
