# Tipografia local

Famílias usadas no site institucional:

- **Manrope** — títulos, hero e hierarquia editorial.
- **Inter** — navegação, corpo, formulários e componentes.
- **IBM Plex Mono** — etiquetas técnicas, códigos e estados.
- **Ethnocentric** — preservada apenas nos ativos de identidade que dependem do logotipo legado.

Os arquivos WOFF2 foram subsetados para o conjunto latino usado pelo site e são carregados localmente por `css/tokens.css`. As famílias Manrope e IBM Plex Mono são distribuídas sob SIL Open Font License; Inter é distribuída sob SIL Open Font License. Fontes consultadas: Google Fonts, 25/10/2026.
