Perguntas frequentes

Identidade exige contexto de operação.

O review altera o domínio?

A revisão deve observar evidências autorizadas e não pressupõe mudanças. Qualquer teste ativo, alteração ou validação adicional precisa estar previsto e autorizado.

O escopo inclui Entra ID?

Entra ID é uma modalidade relacionada no catálogo. A composição entre Active Directory, Entra ID e Microsoft 365 é definida na proposta.

O resultado garante que não há caminho de ataque?

Não. O review descreve o escopo observado, os controles encontrados e as prioridades identificadas; não garante segurança total.
